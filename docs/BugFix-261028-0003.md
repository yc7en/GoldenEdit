# BugFix-261028-0003 · 外壳模块脚本被静默丢弃

## 缺陷描述

`/shell/` 返回 200，`#ge-root` 存在，但 `shell.ts` 完全没有执行（无 ready、无 article 节点）。
原因：Vite 产物自带 `<script crossorigin>`，而 iframe 文档源是 opaque（`null`），
浏览器将其按跨域请求做 CORS 校验，预览服务未返回 `Access-Control-Allow-Origin`，
脚本被静默丢弃——不执行也不报错。

## 修复方法与实现

- `vite.preview.config.ts` 增加 `stripCrossorigin` 插件，构建时去掉 `crossorigin`；
- `preview_server.rs` 对 shell / plugin / asset 三组 GET 响应统一补
  `Access-Control-Allow-Origin: *`（数据由 token 保护，origin 无所谓）。

## 涉及与修改代码清单

- `vite.preview.config.ts`
- `src-tauri/src/preview_server.rs`
