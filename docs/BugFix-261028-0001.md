# BugFix-261028-0001 · 构建被批量删除保护拦截

## 缺陷描述

`npx tauri build` 阶段 `vite build` 以 `emptyOutDir: true` 清空 `dist/assets`（91 个文件），
受管环境的 node-safe-delete shim 拦截超过阈值的批量删除，构建中断：
`[SAFE_DELETE_BULK_CONFIRM_REQUIRED]`。

## 修复方法与实现

- 两个 vite 配置（`vite.config.ts`、`vite.preview.config.ts`）改为 `emptyOutDir: false`；
- 产物文件名均带内容哈希，不清空不会产生错引用；需要彻底重建时手动 `rm -rf dist dist-preview`。

## 涉及与修改代码清单

- `vite.config.ts`
- `vite.preview.config.ts`
