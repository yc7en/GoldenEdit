# R-261028-0003 · 左栏沉底分组与版本时间线

## 一、变更背景与原因

原型 v4 的左栏把「文件」和「大纲」并排放在同一个自上而下的流里，底部再挂一张「渲染正常 · 38ms」卡片。走查时暴露三个问题：

1. **折叠方向不符合直觉**：文件树是自上而下生长的，收起向上没问题；但大纲、版本这类「常驻参考信息」放在下半屏时，收起后头部仍停在原处，视觉上像被凭空掏空，需要用户重新寻找入口。
2. **渲染卡片占位过重**：占掉约 90px 高度，信息（插件数 + 耗时）与预览标题栏重复，点开后也没有明确去处。
3. **缺少版本感**：作为本地优先的编辑器，用户看不到「这份文档/这个项目在什么时候被改过」。左栏底部正好有一块常驻空间。

因此把左栏改成分层结构：顶部区放会变长的内容（文件），底部区放稳定的参考信息（大纲、版本），并让底部区整体沉底、向下收起；渲染卡片删除。

## 二、变更具体内容

### 2.1 去掉渲染卡片

- 删除 `side__promo` 区块与 `promo` 系列样式，以及「打开诊断」按钮。
- 渲染耗时信息保留在预览面板标题栏的「6 插件 · 38ms」，不再在左栏重复。

### 2.2 折叠方向

- 分组区改为纵向 flex，底部区包一层 `.side__bottom{margin-top:auto}`。
- 文件分组在顶部：收起时分组头留在原处。
- 大纲、版本分组在底部：收起时整块高度收缩，块底固定，分组头向下回落到最下方。
- 内容超出可用高度时 `margin-top:auto` 退化为 0，滚动行为不变。
- 折叠动画：`group__body` 改为 `display:grid` + `grid-template-rows:1fr → 0fr`，配 `.group__inner{overflow:hidden}`，220ms 缓动；此前是 `display:none`，无过渡。

### 2.3 版本时间线

- 新增「版本」分组，位于大纲之下。
- 每条记录：圆点 + 版本号 + 短哈希 + 日期 + 一行提交说明；最新一条圆点为金色。
- 竖线由 `::before` 绘制，最后一条不画，避免尾部悬空。
- 数据来源为 git 提交（当前原型用三条真实提交占位：`1fcb2b4` / `bc53f41` / `89c7367`）。

### 2.4 高度配平

窗口 780px 下，左栏分组区可用高度约 454px。删除卡片后释放约 90px，但仍需压缩：文件分组由 5 行减为 4 行（去掉 `原型草图.md`）、沉底区上边距 10→8、时间线条目间距 6→5，最终约 439px，留 15px 余量，保证默认状态不出现滚动条。
