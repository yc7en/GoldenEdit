# R-261028-0006 · 对话插件测试用例补全与核心语法解析增强

## 变更背景与原因

用户在 `docs/demo.md` 中贴入了一份包含全部 Markdown 扩展语法的测试示例文档，要求：
1. 补充对话（`dialogue` / `chat`）插件的完整测试用例；
2. 确保文档内全部插件语法均可正确解析与渲染。

在对 `demo.md` 进行语法解析回归排查中，发现两处语法解析缺口：
- 原渲染内核仅支持行内 `$ ... $` 公式，未对标准 `$$ ... $$` 块级数学公式做切块支持；
- 原提示框插件仅支持 `::: note` 容器语法，而实际主流使用场景（包括 `demo.md`）大量采用 Obsidian 风格的引用提示框（`> [!NOTE]`、`> [!TIP]`、`> [!WARNING]` 等）。

因此，本轮不仅在 `demo.md` 中补齐了对话插件测试用例，同时对渲染内核做了语法兼容扩展。

## 变更具体内容

1. **补全对话插件测试用例**：
   - 在 [docs/demo.md](file:///j:/CODE/GoldenEdit/docs/demo.md) 尾部增加 `## 对话与 Chat 测试` 章节；
   - 增加 `::: chat` 智能问答气泡样例（用户气泡靠右、AI 气泡靠左，支持 Markdown 粗体与编号列表等内联格式）；
   - 增加 `::: dialogue` 团队研发发布评审会场景样例（支持 `(右)` 位置修饰与多发言方角色展示）。

2. **对话插件发言方灵活配置**：
   - 优化 [frontend/plugins/dialogue/entry.js](file:///j:/CODE/GoldenEdit/frontend/plugins/dialogue/entry.js)：支持通过 `(右)` 或 `[right]` 显式指定气泡朝向，并在界面渲染时自动清洗去除修饰标签。

3. **块级 LaTeX 公式解析支持（`$$ ... $$`）**：
   - 在 [frontend/preview-shell/worker/parse.ts](file:///j:/CODE/GoldenEdit/frontend/preview-shell/worker/parse.ts) 中新增 `ge_math_block` 块级解析规则；
   - 支持多行及单行 `$$ ... $$` 块级公式提取，并包装为 `data-ge-plugin="katex"` 的挂载块，由 KaTeX 渲染。

4. **Obsidian 引用提示框语法支持（`> [!NOTE]`）**：
   - 在 `parse.ts` 的 `inst.core.ruler` 中新增 `ge_obsidian_callout` 规则；
   - 识别 `[!NOTE]`、`[!TIP]`、`[!WARNING]`、`[!DANGER]`、`[!SUCCESS]`、`[!TODO]`、`[!ATTENTION]` 等全部主流 Obsidian 类型；
   - 保持内部所有段落、列表、代码块、内联公式等 Markdown 元素的完整解析，同时赋予 Callout 视觉边框与图标。
