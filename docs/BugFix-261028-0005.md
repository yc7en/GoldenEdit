# BugFix-261028-0005 · opaque origin 禁止创建 Worker

## 缺陷描述

消息通了、主题注入了，但 Worker 创建失败：
`SecurityError: Failed to construct 'Worker': ... cannot be accessed from origin 'null'`。
浏览器硬性规定 Worker 脚本必须与文档同源，opaque origin 无解。
渲染内核把 markdown-it 与 L1 插件放在 Worker 里（架构 §6.1），此路不通则整条内核失效。

## 修复方法与实现

- iframe sandbox 由 `allow-scripts` 改为 `allow-scripts allow-same-origin`，外壳获得
  `http://127.0.0.1:{port}` 真实源，Worker 可创建；
- 隔离性不受损：与宿主 `tauri.localhost` 仍跨源，`window.parent.document` 被
  SecurityError 拦截；子框架 invoke 经探针验证不会被执行（ARCHITECTURE §11.1）；
- 外壳入口增加 IPC 可见性告警，作为行为变化的哨兵。

## 涉及与修改代码清单

- `frontend/index.html`
- `frontend/preview-shell/shell.ts`
- `docs/ARCHITECTURE.md`（§11 重写、§13.1 新增升级复验探针）
