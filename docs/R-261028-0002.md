# R-261028-0002 · 左栏分组化与预览面板开合方式调整

## 一、变更背景与原因

原型 v3 的左栏是单一文件树，大纲是右侧浮层抽屉，预览依赖右缘 34px 竖向把手收起。实际走查时有三个问题：

1. **左栏信息层级不足**：文件树只能表达「文档在项目里的位置」，无法承载应用级入口（新建、插件、导出），这些入口只能挤在标题栏，形成一排同质化的 chip，识别成本高。
2. **大纲位置错误**：写长文档时大纲是持续性需求，浮层抽屉需要反复开关，且滑出时遮挡预览。
3. **收起入口隐蔽**：预览收起后只剩一条竖把手，快捷键记不住的用户容易找不到恢复入口。

参照桌面端成熟形态（WorkBuddy 等工作台类应用），把左栏做成「品牌区 + 导航区 + 分组区 + 固定底栏」，把右侧面板的开合收敛到标题栏最右端的方形按钮。这样导航与文档结构分层，收起状态也始终有可见入口。

## 二、变更具体内容

### 2.1 左栏结构

- 宽度由 190px 调整为 208px，自上而下四段：
  - **品牌区**：应用名、版本号、右侧「工作区 ▾」切换；下方一条分隔线。
  - **导航区**：新建文档、打开文件夹、插件（带数量徽标）、导出（带快捷键提示）。
  - **分组区**（可滚动）：`文件`、`大纲` 两个可折叠分组，分组头显示条目数，hover 显示 `+`。
  - **底栏**：固定的「渲染诊断」卡 + 用户条（头像、名称、本地工作区、设置与主题按钮）。
- 仅分组区滚动，诊断卡与用户条固定，与分组内容不重叠。

### 2.2 大纲

- 从右侧浮层抽屉改为左栏内与文件并列的分组，缩进表达层级，当前项左侧金色标记。
- `Ctrl+Shift+O` 语义从「开合浮层」改为「折叠/展开大纲分组并滚入视口」。

### 2.3 预览面板

- 移除 34px 竖向把手与 rail 组件。
- 开合入口为标题栏最右端方形面板按钮，开启态为金色高亮；面板标题栏内保留 `×`；双击分隔条收起的行为不变。
- 收起动画保留 `flex-basis` 过渡，叠加 22px 位移与淡出，不再瞬间消失。

### 2.4 内容页

- 插件等内容页由覆盖全窗改为从 `left:208px` 开始，保留左栏、隐藏标签栏；左栏对应导航项高亮。
- 导出仍以模态覆盖全窗，`Esc` 关闭。
