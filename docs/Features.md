# GoldenEdit 功能清单

> 每条一句话。状态：✅ 已实现 / 🚧 开发中 / 📋 规划中 / 🗑 废弃。
> 架构约束见 `ARCHITECTURE.md`，本文件只描述「用户能用什么」。

## 项目基线

- ✅ 以 Rust + Tauri 2 重建，旧 Wails 实现归档为 `GoldenEdit.7z` 不再维护
- ✅ 架构契约、功能清单、变更记录三份文档建立并互相约束

## 核心编辑

- 📋 Monaco 编辑器承载 Markdown 源码，`golden-dark` 暗色主题
- 📋 编辑、保存、未保存圆点标记、`Ctrl+S` 手动保存
- 📋 崩溃后自动恢复未保存内容
- 📋 外部程序改动当前文件时顶部提示「重载 / 保留我的」
- 📋 命令面板（`Ctrl+Shift+P`）覆盖全部操作入口

## 布局与交互

- 📋 左栏常驻，自上而下为品牌区、导航区（新建 / 打开文件夹 / 插件 / 导出）、分组区、底部用户条
- 📋 文件分组位于顶部，收起后分组头留在原处；大纲与版本分组沉底，收起后分组头回落到最下方
- 📋 分组折叠有高度过渡，内容收起时分组头平滑下滑，不瞬间跳变
- 📋 文件与大纲作为左栏内两个可折叠分组，分组头显示条目数量
- 📋 文件分组支持展开折叠、懒加载、右键新建/重命名/删除、拖入文件
- 📋 版本分组以时间线展示 git 提交：版本号、短哈希、日期与提交说明，最新一条高亮
- 📋 顶部多标签页，可关闭、可切换、标记未保存
- 📋 三种布局：分栏 / 仅编辑 / 仅预览（`Ctrl+1/2/3`）
- 📋 预览为右侧面板，由标题栏最右端方形按钮开合，收起后编辑区限宽 1100px 居中
- 📋 插件、导出等导航页占据内容区，保留左栏并隐藏标签栏
- 📋 分栏比例按文件记忆，下次打开复原
- 📋 导出以模态覆盖全窗，同一时刻只允许一个模态
- 📋 底部状态条显示字数、阅读时长、分栏比例、行列号、编码

## 预览渲染

- 📋 markdown-it 渲染管线，插件按围栏 / 容器 / 定界符三类语法触发
- 📋 预览运行在独立源 iframe 内，不可编辑、不可执行文档内脚本
- 📋 悬停块左侧显示行号角标，点击跳到源码对应行
- 📋 正文区域保持原生选区与双击选词，不被跳转拦截
- 📋 渲染错误在块内显示错误卡片与重试，不整页白屏
- 📋 预览顶部可切换 A4 / 980px / 390px 三种内容宽度
- 📋 预览宽度与主题在导出对话框中复用同一套渲染结果

## 插件体系

- 📋 插件以「一个目录」为单位安装，内置 JS 与 CSS 即可生效
- 📋 插件管理页：卡片列表、开关、按 schema 自动生成的配置表单、搜索过滤
- 📋 勾选插件后预览即时重渲染，无需重启应用
- 📋 三级权限标注（L1 纯渲染 / L2 操作 DOM / L3 需网络或本地程序），安装前可见
- 📋 插件文件变更后自动重载，重载失败回退到上一版本并在页面提示
- 📋 渲染诊断面板：列出每块命中的插件、耗时、错误堆栈
- 📋 从文件夹拖入安装、打开插件目录、卸载
- 📋 内置插件：提示框、标题编号与目录、Mermaid、KaTeX、代码块工具条、表格增强、对白容器

## 主题与外观

- 📋 四档主题预设：跟随系统 / 写作模式（暗编辑 + 亮预览）/ 全亮 / 全暗
- 📋 编辑器与预览可分别指定主题，互不影响
- 📋 插件颜色全部走 `--ge-*` 变量，切换主题不破相
- 📋 用户可追加自定义预览 CSS 作为皮肤

## 导出

- 📋 导出单文件 HTML，图片与字体 base64 内联，离线可开
- 📋 导出 PDF，Windows 下静默输出，可控制纸张与边距
- 📋 导出前可选择格式、宽度、主题、是否内联插件脚本
- 📋 导出结果与预览像素一致（同一段渲染代码，非两套实现）

## 性能

- 📋 块级增量更新，编辑一段只重建对应块，图表不重绘、折叠状态不丢
- 📋 首屏只渲染前 200 块，其余空闲时追加
- 📋 输入防抖 150ms + 代际取消，连续输入不积压过期批次
- 📋 解析与 L1 渲染在 Worker 中执行，主线程不阻塞
- 📋 按文档大小分级降级，超过 10MB 自动暂停预览并提供手动渲染

## 文件与项目

- 📋 打开文件夹作为 vault，记录最近项目
- 📋 打开单个文件、拖入文件、命令行 `goldenedit <file>` 打开
- 📋 文件系统监听，外部改动实时反映到文件树
- 📋 设置持久化到应用数据目录，不污染用户文档目录
