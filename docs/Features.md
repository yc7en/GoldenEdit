# GoldenEdit 功能清单

> 每条一句话。状态：✅ 已实现 / 🚧 开发中 / 📋 规划中 / 🗑 废弃。
> 本文件随版本发布生成，描述当前版本「用户能用什么」。
> 「已实现」指代码完成且通过类型检查 / 单测 / 构建；尚未做真机点验的条目标 🚧。

**基线**：以 Rust + Tauri 2 重建，旧 Go + Wails 实现归档为 `GoldenEdit.7z`，不再维护。

## 1 核心编辑

| ID | 功能 | 一句话描述 | 状态 |
|---|---|---|---|
| F-EDT01 | Monaco 编辑器 | 以 Monaco 承载 Markdown 源码，提供 `golden-dark` / `golden-light` 双主题 | ✅ 已实现 |
| F-EDT02 | 手动保存 | `Ctrl+S` 保存当前文件，未保存时标签显示圆点标记 | ✅ 已实现 |
| F-EDT03 | 崩溃草稿恢复 | 输入后 500ms 落草稿到本地，重开该文件时提示恢复或丢弃 | ✅ 已实现 |
| F-EDT04 | 外部改动冲突 | 外部程序改动当前文件时弹出「重载 / 保留我的」，不静默覆盖输入 | ✅ 已实现 |
| F-EDT05 | 命令面板入口 | `Ctrl+Shift+P` 覆盖新建、打开、保存、关闭、预览、大纲、插件、导出、设置 | ✅ 已实现 |
