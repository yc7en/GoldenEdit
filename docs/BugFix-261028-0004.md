# BugFix-261028-0004 · 沙箱消息通道双向不通

## 缺陷描述

外壳脚本已运行到最后一行（发出 `ready`），但宿主收不到；宿主发的 `init` 外壳也收不到。
原因：消息通道两端都用 URL origin 做校验/定向——
宿主侧 `e.origin !== server.origin` 丢弃了 origin 为 `null` 的握手消息；
宿主 → iframe 的 `postMessage(msg, server.origin)` 因目标文档是 opaque origin 被浏览器直接丢弃。

## 修复方法与实现

- 宿主侧改为只校验 `event.source === iframe.contentWindow`，origin 仅在非 `null` 时比对；
- 所有发往 iframe 的消息 targetOrigin 改为 `*`（凭证在 src 的 token 上）。
