# BugFix-261028-0008 · 修复提示框高级语法未正确渲染及数学公式重复显示文本缺陷

## 缺陷描述

1. **Obsidian / 扩展提示框语法未能正确识别与渲染**：
   用户在 Markdown 中书写高级 Obsidian 提示框语法时（如 `> [!TIP]+ 默认展开`、`> [!EXAMPLE]- 默认折叠`、`> [!EXAMPLE|closed]`、`> [!DANGER|color:#ff5722]`、`> [!QUESTION|type:example color:pink]`、`> [!WARNING|purple meta-demo]`）以及旧式 `!!!type{...}` 语法块时，在预览窗口中直接退化成了普通的 Markdown 引用块（灰底、未分词的 `[!TIP]+` 原始标记文本暴露在段首），没有呈现出交互式折叠条、自定义强调色背景与语义化图标。
   **根本原因**：
   - `frontend/preview-shell/worker/parse.ts` 中原 `ge_obsidian_callout` 正则未按首行与后续正文划分，在多行段落（包含 `\n`）时由于未跨行处理导致正则匹配返回 `null`，导致含正文的提示框直接跳过解析退化为普通引用；
   - 解析时未识别折叠修饰符 `[+-]`、元数据 `|` 槽位中的属性（`color:`、`icon:`、`open`/`closed`/`collapsible`、`type:` 覆盖、自定义类名等），且未输出 HTML5 原生可折叠的 `<details>` / `<summary>` 结构；
   - 缺少对旧版 `!!!type{title/attrs}` 容器块规则的处理。

2. **数学公式（KaTeX）双重重复与布局坍缩**：
   在公式块（如 $\int_0^1 x^2 dx = \frac{1}{3}$、矩阵 $A = \begin{pmatrix} \alpha & \beta \\ \gamma & \delta \end{pmatrix}$）以及行内公式下方，均伴随着一行错乱的纯文本（例如 `∫01 x2 dx = 31`、`A = (αγβδ)`、`a2 + b2 = c2`）。
   **根本原因**：
   - Chromium / WebView2 具备原生 MathML 支持（可天然绘制清晰的根号、积分号、大括号、上下标与分数），而 KaTeX 默认会同时输出 `.katex-mathml` 与未加样式的 `.katex-html` 树；
   - 宿主环境中未打包 KaTeX 专用 WebFont 字体及繁杂的 CSS 排版规则，`.katex-html` 内部的所有 span 在浏览器中按普通内联流展开，坍缩成一串错位的纯文本（如 `∫01 x2 dx = 31`）；
   - 若错误地禁用 MathML 而保留 `.katex-html`，将导致原本正确渲染的 MathML 公式消失，仅留下一串错乱的文本。

## 修复方法与实现

1. **Obsidian 提示框与旧语法块解析器重构**：
   - 修改 [frontend/preview-shell/worker/parse.ts](file:///j:/CODE/GoldenEdit/frontend/preview-shell/worker/parse.ts)：
     - 采用分行正则 `^\[!([a-zA-Z0-9_-]+)(?:\|([^\]]*))?\]([+-])?(?:[ \t]+([^\n]*))?(?:\n([\s\S]*))?$` 精确剥离首行标记与标题，并将后续正文安全放回段落 token 中由 markdown-it 自然解析子元素（包含嵌套、列表、表格、代码块等）；
     - 完整解析 `|` 槽位：支持 `color:...` / 裸颜色名注入自定义强调色变量 `--ge-callout-custom-color`、`icon:...` / `no-icon` 自定义或隐藏图标、`type:` / `kind:` 别名覆盖、`open` / `closed` / `collapsible` 折叠开关，以及将未知词映射为 `mdext-admonition--meta-<name>` 自定义样式类；
     - 增加 `ge_legacy_admonition` 块规则，无缝支持 `!!!type{title/attrs}` 兼容语法；
     - 当提示框配置了折叠标记（`+`/`-`、`open`/`closed`、`collapsible`/`fold`）时，自动生成原生语义化的 `<details class="ge-callout ge-callout--foldable">` 与 `<summary class="ge-callout__header">` 结构，附带右侧折叠箭头指示符。

2. **Callout 样式体系完善**：
   - 更新 [frontend/plugins/callout/style.css](file:///j:/CODE/GoldenEdit/frontend/plugins/callout/style.css) 与 [frontend/preview-shell/plugins.css](file:///j:/CODE/GoldenEdit/frontend/preview-shell/plugins.css)：
     - 补齐 `<details>`、`<summary>` 交互折叠箭头旋转动画与光标手势；
     - 为标题栏增加基于强调色变量的透射背景色（`color-mix(in srgb, var(--ge-callout-color) 10%, transparent)`）；
     - 支持 `example`、`purple` 等扩展类型的语义配色。

3. **数学公式切换为 Chromium 原生 MathML 输出**：
   - 修改 [frontend/plugins/katex/entry.js](file:///j:/CODE/GoldenEdit/frontend/plugins/katex/entry.js)：显式指定 `katex.render(math, el, { output: 'mathml' })`，完全剔除未带外部字体与 CSS 支持的冗余 `.katex-html` 节点，纯净利用 Chromium 内核内置的 MathML Core 引擎进行高性能离线排版；
   - 更新 [frontend/plugins/katex/style.css](file:///j:/CODE/GoldenEdit/frontend/plugins/katex/style.css) 与 [frontend/preview-shell/plugins.css](file:///j:/CODE/GoldenEdit/frontend/preview-shell/plugins.css)：为块级公式与行内公式设定统一的字体大小、明暗主题颜色（`--ge-fg`）与居中排版支持。
