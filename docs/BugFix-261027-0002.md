# BugFix-261027-0002 exe 启动即崩

## 缺陷描述

首次编译出的 GoldenEdit.exe 双击无窗口，命令行运行报错：
`AssetServer options invalid: either Assets, Handler or Middleware must be set`。

## 修复方法与实现

Wails v2 生产构建需要把 `frontend/dist` 通过 `embed.FS` 注入 AssetServer。原来 AssetServer 留空，开发期靠 Vite dev server，打包后没有资源可加载。

- 新增 `embed.go`：`//go:embed all:frontend/dist var assets embed.FS`。
- `app.go`：`AssetServer: &assetserver.Options{Assets: assets}`。

## 涉及与修改代码清单

- `embed.go`（新增）
- `app.go`
