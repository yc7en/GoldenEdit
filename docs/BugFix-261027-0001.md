# BugFix-261027-0001 首次构建失败修复

## 缺陷描述

执行 `wails build` 时前端 `tsc && vite build` 报错：
1. 7 个插件 `import '../../../src/plugins/types'` 相对路径多一级。
2. manager.ts 用默认导入，但插件只导出命名 `{manifest, register}`。
3. PowerShell 批量写文件把中文串编码损坏，导致 codebar/heading-number/callout/dialogue/katex/mermaid 出现 Unterminated string。
4. katex 用了 `require('katex')`，浏览器 ESM 不支持。
5. markdown-it-texmath 无类型声明。
6. monaco markdown worker 路径在 vite 下解析失败。

## 修复方法与实现

- 插件相对路径统一改为 `../../src/plugins/types`。
- 每个插件末尾追加 `export default { manifest, register }`。
- 用 Write 工具（UTF-8）重写所有插件文件，修复乱码。
- katex 改为 ESM `import texmath from 'markdown-it-texmath'` + `import katex from 'katex'`。
- 新增 `frontend/src/shims.d.ts` 声明 `declare module 'markdown-it-texmath'`。
- monaco 只保留 editor.worker，去掉 markdown worker。
- manager.ts 补回 `builtin` 数组。

## 涉及与修改代码清单

- `frontend/src/plugins/manager.ts`
- `frontend/src/editor/setup.ts`
- `frontend/src/shims.d.ts`（新增）
- `frontend/plugins/*/register.ts`（7 个）
