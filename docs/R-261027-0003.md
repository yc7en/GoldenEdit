# R-261027-0003 插件运行时与内置插件

## 变更背景与原因

需要把架构文档第 4 节的插件契约和第 11 节的迁移清单落地。两个 VSCode 插件项目的渲染逻辑要变成 GoldenEdit 内置插件。

## 变更具体内容

- `src/plugins/types.ts`：PluginManifest/PluginContext/LoadedPlugin 类型。
- `src/plugins/manager.ts`：内置插件注册表、applySettings 启停、buildMarkdownIt 装配、onMount 队列。
- `src/preview/pipeline.ts`：渲染管线（render -> innerHTML -> runMounts）。
- `frontend/plugins/callout/register.ts`：Obsidian `> [!NOTE]` 提示块。
- `frontend/plugins/heading-number/register.ts`：标题多级编号 + `[TOC]`。
- `frontend/plugins/mermaid/register.ts`：```mermaid -> 占位 div，onMount 异步渲染。
- `frontend/plugins/codebar/register.ts`：代码块工具条 + 复制 + 行内代码强调。
- `frontend/plugins/katex/register.ts`：markdown-it-texmath + KaTeX。
- `frontend/plugins/table-gfm/register.ts`：启用 GFM 表格/strikethrough。
- `frontend/plugins/dialogue/register.ts`：`::: dialogue` 容器。
- `src/style.css`：补 callout/codebar/toc/mermaid/dialogue 预览样式。
- `package.json`：新增 katex/markdown-it-texmath/mermaid 依赖。
