# R-261028-0005 · P5 内置插件全量交付与 P11 导出链路装配

## 变更背景与原因

在前期 R-261028-0004 与真机调试（BugFix-261028-0001~0005）完成后，GoldenEdit 骨架、文件层与沙箱渲染管线已全通，但留下了两处关键缺口：
1. **P5 内置插件尚未创建**：`frontend/plugins/` 目录为空，`builtin_roots()` 扫不到任何插件，无法提供核心差异化 Markdown 增强体验；
2. **P11 导出单文件 HTML 链路未接通**：外壳 `shell.ts` 未处理宿主发送的 `export` 消息，导致导出弹窗一直停留在「正在渲染导出内容…」。

按照 `docs/PLAN.md` 执行顺序，本轮集中完成 P5 全部内置插件的开发以及 P11 导出链路的装配。

## 变更具体内容

### 1. P5 内置插件（全部 8 个，覆盖 L0、L1、L2 完整能力分级）
- **`callout` (L1)**：语义提示框容器，支持 note、tip、warn、danger、success、quote 等类型，标题与图标语义自适应，所有色彩走 `--ge-*` 变量。
- **`table-gfm` (L1)**：GFM 表格横向溢出包裹器与斑马纹优化，通过 `ctx.onCoreRule` 规则透明包装。
- **`heading-number` (L1)**：标题层级自动编号，通过 `ctx.onCoreRule` 统计 h1-h6 并在内联前缀注入编号。
- **`mermaid` (L2)**：离线交互式图表，Worker 提取源码占位，主线程异步加载 mermaid 模块并挂载 SVG 结果，自适应亮/暗主题。
- **`katex` (L2)**：行内 `$...$` 定界符与块级 `math/katex/latex` 离线数学公式渲染。
- **`codebar` (L2)**：为所有主流语言代码块提供语言徽章与一键复制功能。
- **`dialogue` (L1)**：对话/气泡容器，区分左右发言方与气泡样式。
- **`typographer` (L0)**：纯 CSS 排版增强覆盖，优化引用块、分隔线与键盘按键效果。
- **色彩与硬编码约束**：所有插件 CSS 严格走 `--ge-*` 变量，`grep -E "#[0-9a-fA-F]{3,6}" frontend/plugins` 结果为 0。

### 2. P11 导出装配
- 在 `frontend/preview-shell/shell.ts` 中实现 `export` 消息处理分支；
- 实现 `buildExportHtml(title)`：展开所有可能分片或视口延迟的块，收集当前文档树内全部 CSS 规则与根元素 `--ge-*` 变量，生成内联完整的单文件 HTML；
- 将结果通过 `send({ type: 'exported', id, html })` 传回宿主，宿主派发 `ge:exported` 并由 `api.saveExport` 落盘。

### 3. 解析器安全隔离
- `worker/parse.ts` 中新增独立的 `subMd` 实例，向插件暴露 `render` 与 `renderInline` 能力，避免插件在解析内部 Markdown 时递归污染主解析器状态。

### 4. 扫描与打包配置
- `src-tauri/src/commands/plugin.rs` 的 `builtin_roots()` 扩展扫描 `frontend/plugins` 目录；
- `src-tauri/tauri.conf.json` 将 `../frontend/plugins` 纳入资源打包。
- 新增单元测试 `scans_builtin_plugins_from_frontend_plugins`，27 条 Rust 单元测试全绿。
