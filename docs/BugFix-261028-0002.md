# BugFix-261028-0002 · 启动即中断，预览整条链路未初始化

## 缺陷描述

真机首启后预览 iframe 无 src、无监听端口。CDP 抓到启动异常：
`TypeError: Cannot read properties of null (reading 'addEventListener')`。
原因是 `main.ts` 仍绑定旧版标题栏的 `#btnPlugins`，改版后该元素已不存在，
异常使 `boot()` 后续（预览服务、主题、插件刷新）全部没有执行。

## 修复方法与实现

- 删除失效的 `btnPlugins` 绑定（入口已由左栏 `navPlugins` 承担）；
- 新增 `bind(id, handler)` 辅助：元素缺失时 `console.warn` 并跳过，而不是抛错中断整个启动。

## 涉及与修改代码清单

- `frontend/src/main.ts`
