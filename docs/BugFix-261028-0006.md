# BugFix-261028-0006 · context.ts 违反 no-this-alias 规则导致 lint 失败

## 缺陷描述

执行 `npm run lint` 时报：
`frontend/preview-shell/context.ts: 88:11 error Unexpected aliasing of 'this' to local variable @typescript-eslint/no-this-alias`。
原因是 `PluginRuntime.buildContext()` 中使用 `const self = this;` 闭包访问实例属性，被 TypeScript-ESLint 规则拦截，导致 CI/代码检查无法通过。

## 修复方法与实现

- 将 `PluginRuntime` 中的上下文字典构建提取为顶层纯函数 `createPluginContext(runtime: PluginRuntime)`；
- 属性直接通过 `runtime` 参数解构与读取，彻底消除 `this` 别名绑定；
- `npm run lint` 与 `npm run typecheck` 均 0 错误通过。
