# R-261028-0007 · 系统集成、性能验收与体验尾巴收口

## 变更背景与原因

P0–P11 的主干（工作区、编辑器、预览内核、插件体系、导出）已能编译运行，但对照
`docs/PLAN.md` 与 `docs/Features.md` 仍有六块缺口：

1. **P12 系统集成**：没有单实例保护，双击第二个 `.md` 会开出两个窗口；命令行参数没人读；
   窗口拖入文件不响应——这三件事合起来决定「它能不能当一个默认 Markdown 编辑器用」。
2. **P13 性能验收**：四档渲染策略写了，但没有任何可复现的度量手段，无法回答
   「8MB 到底卡不卡」。
3. **三布局**：只有「显示/隐藏预览」两态，没有「仅编辑 / 仅预览」的沉浸态。
4. **自定义预览 CSS**：用户想调字体、行距、宽窄只能改插件。
5. **崩溃恢复**：编辑器崩一次，未保存的输入全丢。
6. **插件热重载**：写完插件必须重启应用才能看到效果。

## 变更具体内容

### 1. P12 系统集成（`src-tauri/src/instance.rs` 新建）

- **单实例**：以回环端口 `47821` 当实例锁。`bind` 成功即主实例并起监听线程；失败则按
  `GE1 <path>` 协议向已有实例转交参数，**只有读到 `OK` 才退出**（避免占端口的无关程序
  让我们误判为「已有实例」）；连不上就降级为「无单实例保护」继续启动，而不是启动失败。
- **命令行与文件关联**：`doc_arg()` 跳过以 `-` 开头的开关，取第一个真实存在的文件；
  前端通过 `take_pending_open` 主动取一次（监听器就绪前事件会丢）。
- **窗口拖入**：接 `onDragDropEvent`，文档拖入即打开，目录拖入即切工作区。

### 2. P13 性能验收

- `scripts/gen-perf-samples.mjs` 生成 200KB / 2MB / 8MB 三档样本（`scripts/fixtures/perf/`
  不入库）。
- `scripts/perf-check.mjs`：**一档一个进程**拉起 release 版，用环境变量把验收清单交给应用，
  应用内用真实渲染管线跑完一档后把结果写回文件并退出。
  - 为什么不用远程调试端口（CDP）：wry 建 WebView2 环境时总会以编程方式设置
    `AdditionalBrowserArguments`，WebView2 因此忽略 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`，
    调试端口时有时无（实测同一份二进制前后两次启动行为不一致）。为了跑测试在发布版里
    固定开一个调试端口更不可接受。
  - 为什么一档一个进程：同一进程里连跑三档时，上一档的懒填充（2MB 有 1.3 万个块）
    会拖住下一档的首屏，实测 8MB 被多算 9 秒。验收要的是「打开这么大的文件要多久」，
    每档都得从干净进程量。
- `PreviewHost.pushAndWait()`：等「这一次」渲染完成，等待位带代际号；`bench()` 记录
  墙钟与分段（防抖 / 投递 / 传输 / 建 DOM / 回调），`settle()` 在每档前把预览打回空白。
- 结果（release，本机）：

  | 档 | 字符 | 块 | 内核 | 墙钟 | 预算 |
  | --- | --- | --- | --- | --- | --- |
  | small-200kb | 116576 | 1360 | 25ms | 546ms | 900ms |
  | medium-2mb | 1202977 | 13736 | 164ms | 965ms | 1600ms |
  | large-8mb | 4828235 | 54644 | 470ms | 733ms | 2000ms |

### 3. 三布局（`Ctrl+1` / `Ctrl+2` / `Ctrl+3`）

`applyLayout(mode)` 切换 `.workspace.layout-*`：分栏 / 仅编辑 / 仅预览；仅预览时编辑区与
分隔条一起让位，预览吃满窗口。布局随 `persistDocState` 按文件记忆。

### 4. 自定义预览 CSS

设置页 textarea，存 `settings.preview.customCss`，随 `theme` 消息下发，外壳写入
`<style id="ge-custom-css">`（清空即移除）。导出时会把样式表内联进 HTML，所见即所得。

### 5. 崩溃恢复

输入后 500ms 把草稿写入 `localStorage`（键 `ge:draft:v1:<vaultId>:<rel>`，按工作区与文件
隔离）；重开该文件时若草稿比磁盘新，弹「恢复 / 丢弃」；保存成功即清除。

### 6. 插件热重载

`watcher::start_plugins` 监听内置与用户插件目录，300ms 合并后抛 `plugins:changed`，
前端重扫插件并重建预览（§5.10：重建 iframe 而不是热替换 register）。
