# 变更记录

> 按时间倒序。架构层面的改动用 **架构变更** 标注；废弃与迁移必须写明去向。

## 0.2.1 · 2026-10-28

### 修复

- BugFix-261028-0001：构建期 vite 清空输出目录触发批量删除保护，`emptyOutDir` 改为手动清理。
- BugFix-261028-0002：`main.ts` 引用已删除的 `#btnPlugins` 导致启动即中断、预览链路不初始化；元素绑定改为缺失时告警。
- BugFix-261028-0003：外壳模块脚本因 `<script crossorigin>` + 无 CORS 头被静默丢弃；构建去除 crossorigin，预览服务补 CORS 头。
- BugFix-261028-0004：沙箱 iframe 的 origin 为 `null`，宿主与外壳的 postMessage 双向被丢弃；改为只校验 `event.source`。
- BugFix-261028-0005：opaque origin 禁止创建 Worker，渲染内核无法启动。

### 架构变更

- 预览 iframe 沙箱由 `allow-scripts` 调整为 `allow-scripts allow-same-origin`：
  opaque origin 无法创建 Worker，渲染 Worker 必须有真实源。隔离性经真机探针复验：
  iframe 与宿主仍跨源，子框架 invoke 不被执行、不产生副作用。
  结论与升级复验要求写入 `ARCHITECTURE.md` §11.1 / §13.2。
- 本次为首批真机运行验证：exe 构建成功，窗口、编辑器、预览渲染（块切分 / data-line /
  表格 / 代码块 / 大纲回传）、预览服务 403 防护均实测通过。

## 0.2.0 · 2026-10-28

### 新增

- 工程骨架：Vite 双构建（主页面 / 预览外壳）、CSP、capabilities、`bridge/` 单一 Tauri 依赖 + lint 边界检查。
- 文件层：`paths.rs` 四条路径守卫与 26 条单测，vault / doc 命令，32MB 上限、`CONFLICT` 冲突检测、回收站删除。
- 预览资源服务：`127.0.0.1:0` + 一次性 token，`/shell`、`/plugin/{id}/{path}`、`/asset` 三组路由。
- 渲染内核：握手与代际号、块切分与 key、morphdom 增量、分片与视口渲染、Worker 解析、四档大小阈值。
- 插件运行时：manifest 校验、`PluginContext`、能力分级检测、Worker 与主线程双环境、三条错误降级。
- 编辑器：Monaco + `golden-dark` / `golden-light`，保存与脏标记、外部改动提示、行号角标跳转。
- 应用外壳：左栏三段与折叠方向、标签页、分隔条拖动、预览面板开合、状态条、内容页、命令面板。
- 主题与状态：四档预设与独立主题、`--ge-*` token 注入、`settings.json` 与 `ui-state.json` 原子写。
- 插件管理页：卡片、开关、schema 表单、安装与移除、诊断列表。
- 导出：导出对话框、`save_export` 落盘、PDF 打印降级、`@page` A4 分页样式。

### 变更

- `Features.md` 状态从规划改为按实现进度标注，未做真机点验的条目一律标 🚧。

### 未完成

- P5 内置插件（`frontend/plugins/` 尚未建立）、P11 导出装配、P12 单实例与命令行、P13 性能样本、P14 打包验证。
- 明细见 `docs/R-261028-0004.md`。

## 0.1.0 · 2026-10-28

**架构变更**：整体由 Go + Wails v2 迁移到 Rust + Tauri 2；渲染管线从主页面迁入独立源的预览 iframe 沙箱；预览资源加载从自定义协议改为本地 HTTP 服务。

### 新增

- `docs/ARCHITECTURE.md`：建立软件设计契约，明确三层边界、插件契约、命令契约与安全模型。
- `docs/Features.md` / `docs/ChangeLog.md`：功能清单与变更流水，纳入提交约束。
- 插件契约：`register(md, ctx)`，`ctx` 收窄为 9 个成员，块包裹与 `data-line` 锚点由管线统一生成。
- 插件能力分级 L0–L3，按运行时访问记录判定，不采信作者自述。
- 渲染管线四层性能策略：块级 morphdom、分片渲染、防抖 + 代际取消、Worker 解析。
- 本地预览 HTTP 服务：`127.0.0.1:0` + 随机 token，服务外壳页、插件资源与 vault 图片。
- 预览交互：块左侧行号角标点击跳转源码，正文保持原生选区行为。
- 主题四档预设，编辑器与预览可独立设置；插件颜色强制走 `--ge-*` 变量。
- 导出：前端生成完整 HTML，Rust 仅负责落盘；Windows 下走 WebView2 `PrintToPdfAsync` 静默出 PDF。

### 变更

- 预览隔离方式：由「同 DOM + 样式作用域」改为「独立源 iframe + postMessage」。
- 资源加载：不再使用 `asset://` 自定义协议，统一走本地 HTTP。
- 插件启停：由「热替换 register」改为「重建预览 iframe」，消除残留状态。
- 分栏比例：由全局单一值改为按文件记忆，存于应用数据目录。
- 主题：由「左暗右亮固定」改为四档预设 + 独立设置。

### 废弃 / 迁移

- Go 后端（`app.go`、`embed.go`、`internal/`）→ 归档为 `GoldenEdit.7z`，不再维护。
- Wails 绑定与 `frontend/wailsjs/` → 移除，改由 `frontend/src/bridge/` 统一封装 Tauri API。
- `frontend/plugins/*/register.ts` 的 VSCode 专属实现 → 按新契约重写，仅保留语法解析与渲染逻辑。
