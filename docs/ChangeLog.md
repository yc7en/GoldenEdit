# 变更记录

> 按时间倒序，标题格式「日期 + 版本号」。只列用户可感知的变化，实现细节不在此展开。

## 2026-10-29 (v0.5.0)

- 新增：命令表与快捷键系统。界面动作统一注册为命令，右键菜单、命令面板、快捷键三处共用同一份定义，键位提示始终反映真实生效值。
- 新增：快捷键设置窗口（设置 → 键盘快捷方式）。可搜索、点击即录制，`Esc` 取消、`Backspace` 解绑、`Delete` 恢复默认，重复键位会提示并可确认接管。
- 新增：文件级剪贴板。复制或剪切后可粘贴到任意目录（含工作区根），同名文件自动生成 `name copy.md`、`name copy 2.md`。
- 新增：内置插件 `markdown-tools`。提供表格格式化（CJK 双宽、保留对齐标记、跳过代码块）、转为待办、标记完成、取消完成、取消待办，每条命令一次 `Ctrl+Z` 整条撤回。
- 新增：命令插件。声明 `permissions: ["editor"]` 的插件可向命令面板与快捷键设置贡献命令，与系统命令同列。
- 新增：左栏宽度可拖动（180–420px）并记住；标题栏按钮、`Ctrl+B`、双击分隔条三条路径统一收起，开合状态下次启动复原。
- 新增：对白气泡配色对齐微信，明暗主题共用一套气泡色。
- 修改：插件自定义配色改为定义在插件自身样式里，改配色只需保存插件文件，不再需要重新构建前端。
- 修复：内置插件在已有用户上永远无法启用（旧启用名单挡住了升级新增的内置插件）。
- 修复：命令面板的键位提示显示旧值，改键位后仍提示原键。
- 架构：新增命令表与上下文菜单契约；明确「改插件 = 0 次构建」的边界。

## 2026-10-28 (v0.4.0)

- 新增：单实例与命令行打开。第二个实例把文件路径转交给已运行实例后退出；`goldenedit a.md` 与双击 `.md` 关联均可直接打开。
- 新增：窗口拖入。文档拖入即打开，目录拖入即切换工作区。
- 新增：三布局切换，`Ctrl+1` 分栏 / `Ctrl+2` 仅编辑 / `Ctrl+3` 仅预览，按文件记忆。
- 新增：自定义预览 CSS。设置页编辑、即时生效，导出时自动带出。
- 新增：崩溃后恢复未保存内容。输入后 500ms 落草稿，重开该文件时提示「恢复 / 丢弃」，保存成功即清除。
- 新增：插件热重载。插件目录变更后 300ms 合并重扫并重建预览，失败按块降级。
- 新增：插件页「打开插件目录」入口。
- 修复：PDF 导出因沙箱缺少 `allow-modals` 而整条链路静默失效。
- 修复：编辑器把「文档变了」当成渲染事件广播，引发无限重渲染，并导致性能验收误判。
- 修复：8MB 文档下表格插件 O(n²) 处理，钩子耗时从 3.1 秒降到 11ms。
- 修复：宿主与预览外壳渲染代际号错位，一次解析失败会让预览永久冻结。
- 修复：切换文档时未作废上一批懒填充队列，大文档首屏被拖后数秒。
- 架构：新增单实例与命令行打开、自定义预览 CSS、性能验收脚本三处契约；更正 PDF 导出的实现描述。

## 2026-10-28 (v0.3.0)

- 新增：8 个内置插件全量交付——提示框、表格增强、标题编号、Mermaid、KaTeX、代码块工具条、对白容器、排版美化。
- 新增：单文件 HTML 导出装配，完整内联样式与 CSS 变量，导出结果可直接分发。
- 新增：Obsidian 风格提示框（`> [!NOTE]` 等）与原生 `$$ ... $$` 块级公式的离线解析。
- 修复：Obsidian 扩展提示框语法在多行块引用中退化为普通引用文本。
- 修复：KaTeX 渲染时无障碍回退文本未隐藏，导致公式与文本双重重复。
- 修复：打开文件夹时无法列举条目；Windows 下路径大小写不敏感匹配缺失。
- 架构：插件获得独立的安全内嵌渲染实例，杜绝递归解析污染主状态。

## 2026-10-28 (v0.2.1)

- 修复：构建期清空输出目录触发批量删除保护，改为手动清理。
- 修复：引用已删除元素导致启动即中断、预览链路不初始化。
- 修复：预览外壳脚本因缺少 CORS 头被静默丢弃。
- 修复：沙箱 iframe 的 origin 为空导致双向消息被丢弃。
- 修复：预览沙箱无法创建渲染 Worker。
- 架构：预览隔离方式调整为 `allow-scripts allow-same-origin`（Worker 必须有真实源），隔离性经真机探针复验。
- 架构：本版为首次真机运行验证，窗口、编辑器、预览渲染与预览服务防护均实测通过。

## 2026-10-28 (v0.2.0)

- 新增：工程骨架，主页面与预览外壳双构建，CSP 与能力白名单收口。
- 新增：文件层完整能力——路径守卫、vault 与文档命令、32MB 上限、冲突检测、回收站删除。
- 新增：本地预览资源服务（回环地址 + 一次性 token），服务外壳页、插件资源与图片。
- 新增：渲染内核——握手与代际号、块切分、增量更新、分片渲染、Worker 解析、四档大小阈值。
- 新增：插件运行时——清单校验、上下文收窄、能力分级检测、主线程与 Worker 双环境、三级错误降级。
- 新增：编辑器与外壳——双主题、脏标记、外部改动提示、行号角标跳转、左栏三段、标签页、状态条、命令面板。
- 新增：主题四档预设与编辑器 / 预览独立设置；设置与界面状态原子写入。
- 新增：插件管理页与导出对话框（含 PDF 打印降级、A4 分页）。

## 2026-10-28 (v0.1.2)

- 新增：左栏「版本」分组，以时间线展示提交：版本号、短哈希、日期与提交说明，最新一条高亮。
- 修改：文件分组改为顶部锚定、向上收起；大纲与版本分组改为沉底锚定、向下收起。
- 修改：分组折叠加入高度过渡，不再瞬间跳变。
- 修改：移除左栏底部固定「渲染耗时」卡片，耗时改由预览面板标题栏承担。

## 2026-10-28 (v0.1.1)

- 修改：左栏改为三段式导航（品牌区 / 导航区 / 分组区）。
- 修改：大纲由右侧浮层抽屉改为左栏内与文件并列的可折叠分组。
- 修改：预览收起入口由竖向把手改为标题栏最右端方形面板按钮。
- 修改：插件页由覆盖全窗改为侧栏右侧展开的内容页，保留左栏。

## 2026-10-28 (v0.1.0)

- 架构：整体由 Go + Wails v2 迁移到 Rust + Tauri 2；渲染管线迁入独立源的预览沙箱；资源加载改为本地 HTTP 服务。
- 新增：插件契约 `register(md, ctx)`，上下文收窄为 9 个成员，块包裹与源码行锚点由管线统一生成。
- 新增：插件能力分级 L0–L3，按运行时访问行为判定，不采信作者自述。
- 新增：渲染四层性能策略——块级增量、分片渲染、防抖与代际取消、Worker 解析。
- 新增：预览交互——块左侧行号角标点击跳转源码，正文保持原生选区行为。
- 新增：主题四档预设，插件颜色强制走统一变量。
- 新增：导出——前端生成完整 HTML，宿主仅负责落盘。
- 修改：预览隔离由「同 DOM + 样式作用域」改为「独立源 iframe + 消息桥」。
- 修改：插件启停由热替换改为重建预览，消除残留状态。
- 修改：分栏比例由全局单一值改为按文件记忆。
- 废弃：Go 后端与 Wails 绑定移除，归档为 `GoldenEdit.7z` 不再维护。
