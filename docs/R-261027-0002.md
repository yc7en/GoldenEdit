# R-261027-0002 Go 后端服务层

## 变更背景与原因

脚手架只有空壳，需要把架构文档第 7 节的 Go Bind 接口落地，前端才能读写文件、打开 vault、持久化设置。

## 变更具体内容

- `internal/fs/vault.go`：`ListVault(dir)` 递归扫描 `.md` 文件树；`ReadFile/WriteFile`。
- `internal/settings/settings.go`：appdata 下 `settings.json`，`Get/Set` 合并持久化。
- `internal/export/export.go`：`HTML/PDF` 写文件；定义 `Exporter` 接口预留二期 pandoc。
