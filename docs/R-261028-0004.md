# R-261028-0004 · 首轮实现落地（P0–P4、P6–P11）

## 变更背景与原因

`docs/PLAN.md` 定下 14 个工作包与一条关键路径。本轮按「垂直切片优先」推进：先把
`打开文件夹 → 编辑 → 保存 → 沙箱 iframe 渲染带 data-line 的 Markdown` 这条链的
支撑结构全部落地，再补内容层（内置插件）与交付层（导出装配）。

选择一次把后端命令与前端骨架都写完，而不是逐包交付，是因为这些包共享同一套类型契约
（`bridge/types.ts` 与 `ARCHITECTURE.md §9.1`），先定形再验证比来回改签名便宜。
